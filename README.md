# 종합계좌

**퇴직연금(DC)·ISA·연금저축·IRP·일반 계좌를 기록하고 들여다보는 앱.**
증권사 앱에서 실제로 한 매매를 계좌 탭에 적어두면, 보유 현황과 배당·손익 추이를
대신 계산해서 보여줍니다.

탭은 **계좌 / 성과 / 설정** 셋입니다. 계좌(퇴직연금·ISA·연금저축·IRP·일반)는
계좌 탭 맨 위의 칩 줄에서 고릅니다 — 칩에 금액이 함께 나오고, 그 위에 전 계좌 합계가 있습니다.
성과 탭에서도 맨 앞의 `전체` 를 고르면 모든 계좌를 합쳐서 봅니다.

계좌를 더하거나 빼려면 `src/accounts.py` 의 목록과 `src/store.py` 의 `SEED`,
이 두 군데만 고치면 됩니다.

```
총금액  10,013,490원
평가손익  +21,930원 (+0.24%)   ·  보유 9,013,490 · 현금 1,000,000
2026-10 배당  18,000원

  월중 배당   3종목   평가 2,990,490   +0.92%
  월말 배당   5종목   평가 5,003,640   -0.70%
  기타        1종목   평가 1,019,360   +3.01%
```

> ### ⚠ 먼저 읽어주세요
>
> - **처음 켜면 샘플 데이터가 들어 있습니다.** 실제 보유가 아닙니다.
>   종목당 평가금액을 100만원에 맞춰 둔 예시입니다 — 자기 계좌로 쓰려면 증권사 잔고를 보고
>   수량·매수단가·현금을 고쳐주세요. 아래 [시드 데이터](#시드-데이터) 를 보세요.
> - 이 앱은 **기록·조회용입니다. 실제 매매를 하지 않습니다.**
>   매수·매도 주문은 증권사 앱에서 직접 넣으신 뒤, 그 결과를 계좌 탭에서 종목 줄을 눌러 적어주세요.
> - **투자자문 서비스가 아닙니다.** 종목을 추천하거나 사고팔 때를 알려주지 않습니다.
>   화면의 숫자는 본인이 입력한 값으로 계산한 결과일 뿐입니다.
> - **투자 결과의 책임은 전적으로 사용자에게 있습니다.**
> - 실제 잔고는 항상 증권사 앱에서 확인하세요.

## 시세는 직접 넣습니다

이 앱은 **증권사 API 로 시세를 자동 갱신하지 않습니다.** 현재가는 계좌 탭의
`관리 > 현재가 직접 입력` 으로 넣습니다. API 키 없이 바로 쓸 수 있게 한 것입니다.

한국투자증권(KIS) 계좌와 API 키가 있고 자동 갱신을 쓰고 싶다면
[시세 자동 갱신 켜기](#시세-자동-갱신-켜기-선택) 를 보세요.

## 설치

Python 3.10 이상이 필요합니다. 네 줄이면 끝납니다.

```bash
git clone https://github.com/cleansun-git/jonghap-gyejwa.git
cd jonghap-gyejwa
pip install -r requirements.txt
python -m uvicorn web.app:app --port 8010
```

브라우저에서 `http://localhost:8010` 을 열면 **샘플 데이터가 든 화면이 바로 뜹니다.**
API 키도, 로그인도 필요 없습니다. 자기 계좌로 바꾸는 방법은 아래
[시드 데이터](#시드-데이터) 에 있습니다.

> 비공개 저장소라 `git clone` 에 접근 권한이 필요합니다. 권한이 없으면
> GitHub 에서 **Code > Download ZIP** 으로 받아 압축을 풀어도 똑같이 됩니다.

설치가 잘 됐는지 보려면:

```bash
python tests/test_accounts.py
```

## 실행

```bash
python -m uvicorn web.app:app --host 0.0.0.0 --port 8010
```

브라우저에서 `http://localhost:8010` 을 엽니다.
같은 공유기에 붙은 휴대폰에서는 `http://192.168.x.x:8010` 으로 볼 수 있습니다.

> **집 WiFi(http)로는 휴대폰 알림과 앱 설치가 되지 않습니다.** 브라우저가 알림·서비스워커를
> https 에서만 허용하기 때문입니다. 또 PC 로 돌리면 평일 16:05 에 이 창이 떠 있어야 기록이 쌓입니다.
> 휴대폰 앱처럼 쓰고 알림도 받으려면 **클라우드에 올리세요 → [docs/install-cloud.md](docs/install-cloud.md)**.
> 클라우드로 올렸으면 PC 쪽은 같이 켜두지 마세요 — 기록이 두 곳에 따로 쌓여 어긋납니다.

처음 실행하면 `data/` 폴더가 만들어지고, 아래 **시드 데이터** 로 계좌가 채워집니다.

## 화면 — 탭 3개

| 탭 | 하는 일 |
|---|---|
| **계좌** | 계좌를 고르는 칩 줄과 전 계좌 합계. 총금액 · 평가손익(수익률) · 월 배당 KPI 3개, 배당시기별(월중/월말/기타) 종목 표와 소계, `내일의 전략` 메모. `관리` 에서 현재가 직접 입력, 종목별 매수·매도·수정·삭제, 종목 추가, 현금 수정, 배당 입력, 오늘 마감 저장 |
| **성과** | 총자산 추이 · 누적 평가손익 라인차트, 월 배당 막대차트, 그룹별 비중. 맨 앞 `전체` 는 모든 계좌 합계. 기록이 2일 이상 쌓여야 그려집니다 |
| **설정** | 운용 시작일, 휴대폰 알림(웹 푸시) 켜기·테스트·진단, 현재 설정 요약, 지금 실행, 로그아웃 |

매수·매도는 **가중평균 단가를 다시 계산**합니다. 매도는 평균단가를 바꾸지 않고,
0주가 되어도 종목을 지우지 않고 수량 0 으로 남겨둡니다(그 해 배당·실현손익 기록이 남아야 하니까요).

**색 규칙**: 상승·수익은 빨강, 하락·손실은 파랑입니다.

평일 16:05(KST)에 스케줄러가 한 번 돌면서 그날 마감을 저장합니다.
시세 자동 갱신을 쓰지 않으므로, 직접 넣어 둔 현재가로 기록이 쌓입니다.

주말에는 돌지 않습니다. **공휴일에는 돕니다** — 휴장일 판단에 KIS 휴장일 API 가 필요한데
키가 없으면 확인할 방법이 없어서, 주말만 거르고 평일은 모두 개장일로 봅니다.
공휴일에 쌓이는 줄은 전날과 같은 값이라 성과 그래프에서 평평한 구간으로 보일 뿐입니다.
설정 탭의 `지금 실행` 은 언제든 그대로 돕니다.

## 비밀번호 걸기

휴대폰에서 접속할 거라면 비밀번호를 거는 편이 좋습니다.
`secrets.example.json` 을 복사해 `secrets.json` 을 만들고 `web_password` 를 채우세요.

```bash
cp secrets.example.json secrets.json
```

환경변수 `PEN_PASSWORD` 로 넣어도 됩니다.
클라우드(fly.io)에서는 `flyctl secrets set PEN_PASSWORD=...` 로 넣습니다
→ [docs/install-cloud.md](docs/install-cloud.md).

**비밀번호를 설정하지 않으면 이 PC(localhost) 에서만 열리고 휴대폰에서는 막힙니다.**
남이 내 계좌를 들여다보고 고치는 일이 없게 하려는 것입니다.

| 환경변수 | 뜻 | 기본값 |
|---|---|---|
| `PEN_PASSWORD` | 로그인 비밀번호. 비우면 localhost 전용 | (없음) |
| `PEN_HTTPS` | 쿠키 secure 플래그. 집 WiFi(http) 에서는 `0` | `1` |
| `PEN_NO_SCHEDULER` | `1` 이면 평일 16:05 자동 실행을 끔 | (없음) |
| `PEN_DATA_DIR` | 데이터 폴더 위치를 옮김 | `data/` |

**`secrets.json` 은 절대 공유하지 마세요.** `.gitignore` 에 들어 있습니다.

## 휴대폰 알림 (선택)

기본값은 **꺼짐** 입니다. `config.yaml` 의 `notify.push_enabled` 를 `true` 로 바꾸고
앱을 다시 켜면, 설정 탭에서 알림을 켤 수 있습니다.

VAPID 키쌍은 **처음 켤 때 앱이 스스로 만들어** `data/vapid.json` 에 넣습니다.
따로 발급받을 것이 없고, 설치마다 다른 키를 씁니다.
재배포해도 같은 키를 쓰고 싶으면 `secrets.json` 의 `vapid_public`/`vapid_private` 에 적으세요
(키가 바뀌면 휴대폰에 등록된 구독이 전부 무효가 됩니다).

알림은 https 에서만 옵니다. 홈 화면 아이콘으로 실행해야 하고, 브라우저 탭으로 열면 안 옵니다.

## 시세 자동 갱신 켜기 (선택)

한국투자증권(KIS) OpenAPI 키가 있으면 현재가를 자동으로 받아올 수 있습니다.
**국내 상장 종목(6자리 코드)만 됩니다.**

1. [KIS 개발자센터](https://apiportal.koreainvestment.com) 에서 키를 발급받습니다.
2. `secrets.json` 에 키를 넣습니다.

   ```json
   {
     "kis_app_key": "PSxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx",
     "kis_app_secret": "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
   }
   ```

3. `src/accounts.py` 의 `ACCOUNTS` 에서 자동 갱신을 쓸 계좌의 `"autoPrice"` 를
   `False` → `True` 로 바꿉니다.
4. 앱을 다시 켭니다. 계좌 탭에 `시세 자동갱신` 이 동작합니다.

- 모의투자 키라면 `"kis_paper_trading": true` 를 넣으세요.
- 접근토큰은 `data/.kis_token_cache.json` 에 24시간 캐시됩니다.
  KIS 는 토큰 발급을 **키당 1분에 1번**으로 막습니다 — 같은 키를 쓰는 다른 프로그램이
  정각에 돈다면 `config.yaml` 의 `notify.daily_minute` 를 몇 분 띄워 두세요.
- 안전장치가 두 개 있습니다. 조회한 현재가가 0원 이하면 반영하지 않고,
  조회된 실제 종목명이 저장된 이름과 다르면 그 종목은 건너뜁니다.
  종목코드를 잘못 적었을 때 엉뚱한 가격이 덮어써지는 것을 막기 위한 것입니다.
- `autoPrice` 를 `True` 로 바꾸면 종목코드 규칙이 **영숫자 1~20자 → 국내 6자리**로
  좁아집니다. 6자리가 아닌 코드로 넣어 둔 종목이 있으면 먼저 고쳐야 합니다.

## 데이터 파일

전부 `data/` 안에 있습니다. **git 에 올라가지 않습니다**(`.gitignore`).
백업하려면 이 폴더만 통째로 복사하면 됩니다.

| 파일 | 내용 |
|---|---|
| `data/<계좌>/state.json` | 보유 종목 · 현금 · 전략 메모 · 마지막 시세 갱신 시각 ← 현재 상태 전부 |
| `data/<계좌>/history.csv` | 일별 마감 스냅샷. 성과 탭 그래프의 원천 |
| `data/<계좌>/trades.csv` | 체결·변경 이력 (매수/매도/추가/삭제/수정/현금/배당) |
| `data/<계좌>/dividends.csv` | 배당 입금 기록 |
| `data/push_subs.json` | 휴대폰 알림 구독 정보 |
| `data/vapid.json` | 웹 푸시 키쌍. 지우면 알림을 다시 켜야 합니다 |
| `data/.kis_token_cache.json` | KIS 접근토큰 캐시 (24시간) |

저장은 임시 파일에 쓴 뒤 바꿔치기하고 `.bak` 을 남깁니다.
OneDrive 폴더에서 파일이 잠겨 저장이 실패하는 일을 막기 위해 재시도도 합니다.

## 시드 데이터

`data/<계좌>/state.json` 이 없으면 `src/store.py` 의 `SEED` 에서 그 계좌 시드를 꺼내 만듭니다.

**샘플 데이터입니다.** 실제 보유가 아닙니다. 종목당 평가금액을 100만원에 맞췄고
(`qty = round(1,000,000 / price)`), 매수단가를 현재가에서 ±3% 로 엇갈리게 넣어
손익에 빨강과 파랑이 둘 다 보이게 했습니다. 금액이 전부 떨어지는 숫자인 이유입니다.

- `dc`(퇴직연금) — 9종목 + 현금 100만원, 배당 2건
- `isa`·`pen`·`irp`·`gen` — 종목 없이 현금 100만원씩

제대로 들어갔다면 퇴직연금 탭에 이 값이 나와야 합니다.

| 항목 | 값 |
|---|---|
| 총 매수금액 | 8,991,560 |
| 총 평가금액 | 9,013,490 |
| 현금 | 1,000,000 |
| **총금액** | **10,013,490** |
| **평가손익** | **+21,930 (+0.24%)** |

`월 배당` KPI 는 **오늘이 속한 달에 받은(지급일 기준) 배당 합계**입니다. 시드 배당은
2026-10-02 지급분이라 10월에는 18,000원이 나오고, 달이 바뀌면 0원에서 다시 쌓입니다.
지난 달까지의 합계는 성과 탭의 `누적 배당`·`월 배당` 그래프에서 봅니다.

**자기 계좌로 쓰는 법** — 계좌 탭에서 종목 줄을 눌러 수량·매수단가를 고치고,
`관리 > 현금 수정` 으로 현금을 맞추면 됩니다. 처음부터 비우고 싶으면
`src/store.py` 의 `SEED_HOLDINGS` 를 `[]` 로 두고 `data/` 를 지운 뒤 다시 띄우세요.

## 폴더 구조

```
config.yaml            설정
secrets.json           비밀번호 · (선택) KIS 키 — 직접 만들며, 절대 공유 금지
requirements.txt       필요한 패키지
docs/SPEC.md           빌드 명세서 (무엇을 어떻게 만들었는지)
docs/install-cloud.md  클라우드(fly.io) 배포 순서
tests/                 테스트 (python tests/test_accounts.py — tests/README.md 참고)

src/
  accounts.py          계좌 등록부 — 탭 하나 = 계좌 하나
  settings.py          config.yaml + secrets.json + overrides 로드
  store.py             data/ 읽기·쓰기 (원자적 교체, 백업), 시드 데이터
  market.py            KIS 시세 조회 (autoPrice=True 일 때만 씀)
  daily_close.py       그날 마감 스냅샷을 history.csv 에 기록

web/
  app.py               FastAPI — API + 인증 + 스케줄러 + PWA 서빙
  service.py           계산·비즈니스 로직
  push.py              웹 푸시 (VAPID)
  static/              화면 (index.html / style.css / app.js / sw.js / manifest.json)

data/                  실행하면 생깁니다 (계좌별 하위 폴더)
```
